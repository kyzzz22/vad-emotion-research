## 为什么保留

该项目研究情绪词典的 VAD 坐标能否解释“面部情绪 × 声音情绪”融合后的人类标签共识。虽然它与当前 DREAMER × NRC 的“词义与诱发体验对齐”不是同一个实验，但二者共享一个重要问题：**孤立情绪词的语义坐标能否迁移到更具体、动态和多模态的情绪判断中？**

旧项目中仍有价值的内容包括：

- NRC 与 ANEW 的跨词典坐标比较。
- VAD 二维/三维距离和维度贡献分析。
- 词典坐标与面部×声音融合共识的负结果。
- 排列检验、留一法校正模型和49格预测代码。
- 后续人类验证实验的可检验预测。
- 从早期模型到研究问题重构的完整过程记录。

因此，这些内容被归档到当前仓库，而不再保留一个独立 GitHub 项目。

## 归档结论

旧项目的探索性结果提示：

1. NRC 与 ANEW 对同一组情绪词的偏差具有一定一致性。
2. 词典中的 VAD 几何关系不能直接预测 Savaliya 面部×声音融合实验中的人类共识率。
3. Dominance 对三维距离有不可忽略的描述性贡献，但“约30%”不是独立的因果或显著性结论。
4. 用14个验证点训练校正模型不稳定，不能支持对全部49格作强推广。

这些结论与当前主线的关系是：语义 VAD 可以提供参照结构，但不能未经验证地当作多模态感知或诱发体验的真实坐标。

## 必须保留的限制

- 核心比较只有14个复杂情绪点。
- 其中10个共识率来自对前辈论文定性描述的估算，而非可核验的原始连续评分。
- 数据来自单一融合框架、30名参与者和 AI 生成刺激，不能泛化到所有多模态情绪。
- “D贡献30%”是距离平方分解后的描述性占比。
- 使用500次排列时，常规加一修正下最小经验 p 值约为 `1/501=.002`；旧文档中的 `p<.001` 表述不严谨，重新使用结果前必须复核。
- 部分旧报告包含原电脑的绝对路径，图像链接可能失效；归档的 `figures/` 保存了当前仍可用的主要图表。
- 这些结果没有替代当前 DREAMER × NRC 主分析，也不应并入当前论文的确认性证据。

## 运行方式

```bash
cd archive/multimodal-emotion-fusion-2026
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

将合法取得的词典放到 `data/` 后，再运行 `core/` 中的脚本。部分旧脚本使用相对路径，建议从本归档目录执行。重新使用任何统计结论前，应先核对数据来源、共识率和排列检验实现。
