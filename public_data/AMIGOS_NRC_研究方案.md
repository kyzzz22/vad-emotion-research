# AMIGOS × NRC VAD 公开数据研究方案

## 1. 研究定位

本研究比较离散情绪词在词汇常模中的 VAD 语义坐标，与参与者观看影片后选择同一离散情绪标签时报告的诱发体验 VAD。它检验跨来源表征对齐和几何重排，不把词汇坐标或诱发坐标视为真值，也不把二者差异解释为纯粹的刺激模态因果效应。

建议标题：

> 当情绪词与实际体验占据不同坐标：语义与影片诱发情绪的 VAD 几何及生理增量信息

## 2. 数据来源

### 2.1 诱发数据：AMIGOS 短片实验

- 40 名参与者观看 16 段短情绪视频。
- 每试次包含 valence、arousal、dominance/control、familiarity、liking 和七类基本情绪自选标签。
- 原始或预处理信号包含 EEG、ECG 和 GSR。
- 主分析只使用独自观看短片的第一实验，避免把长片和群体观看情境混入同一估计量。
- 数据必须来自作者或机构认可的原始发布渠道；未经核验的第三方转载不得作为正式分析来源。

### 2.2 语义数据：NRC VAD Lexicon v2.1

- 主要语义来源。
- 词条 V/A/D 范围为 0–1。
- 仅限非商业研究或教学使用；不得随论文数据包重新分发原词典。
- ANEW 仅在七个目标标签全部可核验时作为同量尺敏感性分析，不为追求结果一致而选择词源。

## 3. 分析单位与标签

AMIGOS 的基本情绪标签为 neutral、happiness、sadness、surprise、fear、anger 和 disgust。主映射只使用预先冻结的同名名词词条；形容词或近义词只作为敏感性分析，不能在查看结果后挑选。

主观诱发数据的分析单位是参与者 × 视频试次。语义数据的分析单位是情绪标签。七个语义坐标不能被扩充为数百个独立观测；涉及语义来源的总体推广以七类情绪为边界。

## 4. 量尺统一

AMIGOS 的 1–9 评分映射至 0–1：

```text
x_01 = (x_1_9 - 1) / 8
```

NRC 保持 0–1。正式计算前核对 dominance/control 方向：AMIGOS 应为低分“被情绪压倒”、高分“控制情绪”；NRC 应为低控制/弱到高控制/强。若题意或方向不一致，D 不进入主要三维距离，主要分析改为 VA，D 单独报告。

除 0–1 映射外，不按来源分别 z 标准化，因为来源内标准化会人为删除需要比较的均值和离散程度。参与者内中心化仅用于生理协变量模型和敏感性分析。

## 5. 三组研究问题

### RQ1：每种情绪的语义坐标与诱发体验有多接近？

对每个情绪 `e` 计算 AMIGOS 参与者聚类 bootstrap 的诱发质心和区间，并定义：

```text
delta_e = centroid_induced_e - coordinate_semantic_e
distance_e = sqrt(delta_V^2 + delta_A^2 + delta_D^2)
```

报告有方向的 `delta_V`、`delta_A`、`delta_D`，不能只报告欧氏距离。NRC 每词只有一个常模点，因此这里称“坐标接近/偏离”，不称“两个分布重合”。

### RQ2：语义情绪空间与诱发情绪空间的几何是否一致？

分别构造七类情绪的 7×7 距离矩阵：

```text
D_semantic(e, f)
D_induced(e, f)
```

预定报告：

- 两个距离矩阵上三角的 Spearman 相关，并以情绪标签置换获得区间或 p 值；
- Procrustes 对齐后的残差，只用于整体形状描述；
- 每个情绪对的 `D_induced - D_semantic`，识别语义上接近但体验中分离、以及语义上分离但体验中压缩的情绪对。

只有 AMIGOS 中两类诱发评分分布的重叠才能称为“诱发分布重合”。这部分使用参与者分组交叉验证的 VAD-only 两类分类性能和参与者 bootstrap 距离稳定性，不用单一质心距离冒充分布重叠。

### RQ3：生理信号是否提供 VAD 之外的信息？

对预定且样本量充足的情绪对比较：

```text
M0: emotion_pair ~ V + A + D
M1: emotion_pair ~ V + A + D + baseline-corrected ECG/GSR features
```

- 所有训练、标准化、特征选择和情绪对筛选必须在训练参与者内完成。
- 测试采用按参与者分组的外层交叉验证，禁止同一参与者的窗口同时进入训练与测试。
- 主要增量指标为 held-out balanced accuracy 或 log loss 的 `M1-M0` 差异。
- 高重合与低重合情绪对若由当前数据识别，则该分析标为探索性，并报告参与者 bootstrap 的排名稳定性；不得在同一数据中挑选极端对后再作无修正的确认性检验。

## 6. 纳入和质量规则

- 保留具有有效基本情绪标签和完整 V/A/D 的短片试次。
- 分别报告每类情绪的试次数和独立参与者数。
- 进入成对生理分析的每类情绪至少需要 20 个有效试次且来自至少 10 名参与者；不足者保留在描述图中，不进入分类比较。
- ECG/GSR 质量失败只排除对应模态或试次，不自动删除有效的主观评分。
- 生理特征先相对基线校正，再在训练折内做参与者内或训练样本标准化。
- 多个情绪对的推断使用 Holm 校正；几何排名和探索性图形明确标注 exploratory。

## 7. 主要贡献边界

可以声称：

- 七类情绪的词汇语义坐标与影片后自报体验坐标存在何种对齐和系统位移；
- 情绪对的相对几何在语义与诱发条件中是否保持；
- ECG/GSR 是否为 VAD 高度相似的诱发情绪提供增量区分信息。

不可声称：

- NRC 与 AMIGOS 测量了同一心理对象或同一总体；
- 生理信号给出客观情绪真值；
- 七个标签足以推广到所有复杂情绪；
- 跨数据库差异完全由词义理解与影片诱发造成。

## 8. 获取后立即执行的核验

1. 记录 AMIGOS 正式来源、许可、文件清单和 SHA-256。
2. 检查 `.mat` 结构、参与者数、短片试次数、标签编码和缺失。
3. 核对 V/A/D 量尺端点以及 dominance/control 方向。
4. 统计七类情绪的试次和参与者覆盖，冻结可分析标签。
5. 检查 NRC 七个主词条是否全部存在并冻结词典版本和映射。
6. 在不查看生理结果的情况下冻结主要几何指标和生理特征族。
