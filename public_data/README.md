# 公开数据路线

本目录存放 AMIGOS × NRC VAD 二次分析的方案、映射和后续代码，不存放受许可限制的原始数据库。

## 当前状态

- 已确认 AMIGOS 短片实验包含每试次 V/A/D、七类基本情绪自选标签以及 EEG/ECG/GSR。
- 已确认 NRC VAD v2.1 可用于非商业研究和教学，但禁止重新分发。
- 原 AMIGOS 数据入口当前可能需要账号或联系作者；第三方 Kaggle 副本的来源与许可尚未核验，不作为正式来源。
- 尚未获得或检查 AMIGOS 原始文件，因此参与者缺失、标签编码和有效样本数仍不得写成正式结果。
