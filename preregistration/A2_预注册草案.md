# A2 预注册草案

> 2026-09-28：以下为原三级 A2 的历史设计/方法材料，待修订，不作为当前新研究的招募或执行依据。当前工作见[可行性验证与决策门槛](../protocol/A2_可行性验证与决策门槛.md)。原 H1、30–40 人规模、2026 年 7–8 月时间表及生理配置均未转用于新设计；通过决策关口后须同步更新预注册、材料、代码和分析。

状态：设计草案，尚未冻结。伦理、设备、刺激预测试和功效模拟完成后生成 v1.0 并登记。

## 1. 研究标题

从情绪词到真实感受：词汇联想、情绪概念原型与刺激诱发体验在 VAD 空间中的对齐和偏离

## 2. 研究目的

本研究检验同一情绪概念在三个表征层次中的 VAD 坐标关系：

1. 词汇联想：孤立情绪词本身带来的情感联想。
2. 概念原型：人们对典型情绪体验的语义知识。
3. 诱发体验：观看情绪刺激时实际报告的状态。

主要问题是：概念原型是否比孤立情绪词更接近实际诱发体验。次要问题是这种偏离是否因 V/A/D 维度和具体概念而异，以及生理唤醒是否解释 A 维度的偏离。

## 3. 设计

- 被试内重复测量。
- 语义场次与诱发场次相隔至少 72 小时。
- 场次顺序随机平衡。
- 使用 8 个正交序列同时平衡场次顺序、语义区块顺序和诱发首个视频效价，每序列按预分配编号循环分配。
- 语义场次包含 lexical 和 prototype 两个区块，区块顺序随机平衡。
- 每个参与者评价相同的 6 个情绪概念。
- 每个语义区块另含相同的 12 个 filler，独立随机且不进入主分析；区块间至少休息 3 分钟。
- lexical、prototype 和 induced 条件开始前分别呈现一次三选一评分对象理解核对。记录首次答案；答错后重申正确指令再继续。该指标用于报告任务区分是否被理解，不作为参与者排除标准，也不按其结果筛选主要分析。
- 每概念候选 2 个视频；两者均通过预测试则都进入正式实验，只有一个通过则保留一个。若某概念无候选通过，必须补充并重新预测试，不能在正式数据中事后删除该概念来挽救设计。
- 每个 induced 试次固定为 30 秒紧邻基线、影片、即时评分和 60 秒恢复；短窗口 HRV 不作为主要结果。

## 4. 参与者

### 4.1 纳入标准

- 年龄 18-35 岁的成年人；若伦理批准要求不同，必须在首名参与者前作为预注册变更记录。
- 简体中文母语者或达到母语熟练程度。
- 正常或矫正后正常视听能力。
- 提供有效知情同意。

### 4.2 排除标准

- 未完成任一正式场次。
- 任一场次的两个明确指令检查均答错，即该场通过率低于 50%。每场至少答对一个才保留该参与者；两题均答对作为更严格敏感性样本。
- 在目标概念的可用评分中，超过 20% 的页面总反应时低于 800 ms。该阈值用于识别不可能完成三项判断的极快反应，不根据结果方向调整。
- 任一目标概念缺少 lexical、prototype 或至少一个有效 induced 评分，或未完成两个场次。
- 明确违反任务要求或重复参与。

主观数据和生理数据分别排除。生理信号失败不自动删除该参与者的主观评分。

所有参与者级排除由 `analysis/apply_exclusions.py` 一次性执行并输出逐人原因。不得在模型脚本中增加未注册排除。

### 4.3 样本量

30 名完整参与者是 pilot 定位的最低执行目标，不是已证明充分的确认性样本。正式停止规则由事先规定的最小重要效应、`analysis/power_sensitivity.py` 的参与者层敏感性分析和预测试方差驱动的混合模型模拟共同确定，并在正式招募前冻结。计划招募数按至少 15% 退出和无效率上调。

受一个月执行窗口限制，最多启用 P001-P048 共 48 个预分配编号；2026-08-04 后不新增第一场参与者。达到预测试功效目标、用完 48 个编号或到达日期门槛时停止新增，以最先发生者为准。停止决定不查看 H1 估计值或 p 值。

## 5. 材料

- 6 个情绪概念：喜悦、被逗乐、温情、愤怒、悲伤、恐惧。
- 词项来自中文情感常模，并检查熟悉度、词长、离散情绪纯度和 VAD 分布。
- 12 个候选视频来自 Ge et al.（2019）中文情绪影片常模；正式使用前核实合法访问方式和实验展示权限。
- 所有正式视频通过独立预测试，至少报告目标情绪强度、非目标情绪强度、V/A/D、熟悉度和不适程度。

正式材料以 `materials/emotion_concepts.csv` 和 `materials/stimulus_manifest.csv` 的冻结版本为准。

## 6. 测量

### 6.1 VAD

三种条件均使用基于 SAM 三维构念、方向一致的 1-9 分文字锚定 VAD 量尺；当前任务不呈现 SAM 人偶图形：

- V：1 = 非常不愉悦；9 = 非常愉悦。
- A：1 = 非常平静/低激活；9 = 非常激动/高激活。
- D：1 = 完全被支配、无控制；9 = 完全掌控、有控制。

### 6.2 离散情绪与协变量

- 7 个离散情绪强度：6 个目标概念加厌恶，用于识别愤怒材料的混合情绪。
- 刺激熟悉度。
- 个人相关性。
- 任务理解检查。

### 6.3 生理

最低计划为 EDA 与 ECG/PPG。所有刺激期指标相对紧邻刺激前基线校正。主要生理指标为 EDA 反应和平均 HR/IBI 变化；短窗口 HRV 不作为主要结果。

## 7. 数据处理

### 7.1 量尺标准化

在计算 VAD 距离前，在全体有效观测中按维度标准化：

```text
z_dimension = (score - pooled_mean_dimension) / pooled_sd_dimension
```

标准化参数必须只由正式样本计算，并在所有条件中共享；不得按条件分别 z 标准化，否则会人为消除条件均值和方差差异。

### 7.2 诱发评分聚合

若每概念使用两个视频，先在参与者 × 概念内计算两个有效诱发试次的平均 V/A/D。只有一个有效试次时保留并标记；主分析和仅保留两个有效试次的敏感性分析均报告。

### 7.3 主要距离

```text
distance_LI = sqrt((zV_lexical-zV_induced)^2 +
                   (zA_lexical-zA_induced)^2 +
                   (zD_lexical-zD_induced)^2)

distance_PI = sqrt((zV_prototype-zV_induced)^2 +
                   (zA_prototype-zA_induced)^2 +
                   (zD_prototype-zD_induced)^2)
```

## 8. 假设与分析

### 8.1 唯一主要假设

H1：`distance_PI < distance_LI`。

该估计量比较的是同一参与者、同一情绪概念和同一响应尺度下，两个语义条件相对于诱发条件的坐标接近程度。它不识别“语义加工”或“影片诱发”的纯因果效应，因为条件同时在刺激形式、时间参照、具体性和评分对象上不同；结果只解释为本研究所定义任务条件之间的表征对齐。

先在每个参与者 × 情绪概念单元内形成精确配对差：

```text
distance_difference = distance_PI - distance_LI
```

主要模型：

```text
distance_difference ~ concept(sum-coded) + session_order_centered +
                      prototype_first_centered + (1 | participant)
```

主要参数是模型截距，即六个预定概念上经顺序校正的平均 `PI-LI`；负值支持 H1。概念使用和为零编码，使截距对应六概念总体而非任一参照概念。`session_order` 以 1.5 为中心；`prototype_first` 以 0.5 为中心。双侧 alpha = .05，报告估计值、95% CI、p 值和参与者层配对 `dz`。

六个情绪概念是有目的选取而非从情绪总体随机抽样，因此在主要模型中作为固定控制项，结论限定于这六类概念。若参与者随机截距 LMM 经 `lbfgs` 和 `powell` 均不收敛，或随机截距方差不大于 `1e-8`，则使用同一固定效应公式的 OLS，并以参与者为聚类单位计算带有限样本校正的稳健标准误和 t 检验。实际采用的路径、奇异性和所有简化均报告。

把两条距离保留为长表的原 source 模型仅作敏感性分析，不取代上述精确配对主要模型：

```text
distance ~ source + concept + session_order + block_order +
           (1 + source | participant)
```

各概念的原始 `PI-LI` 配对差及区间用于探索异质性，不改变总体截距的主要检验地位。

### 8.2 次要假设

- H2：D 的标准化绝对跨条件偏差大于 V，即 D 的跨条件一致性低于 V。
- H3（探索性）：参与者内 EDA/HR 变化与 induced A 和 `Delta_PE_A` 相关。

H2 将每个 source（lexical/prototype）与 induced 的逐维标准化绝对差作为因变量：

```text
absolute_difference ~ dimension + source + concept +
                      session_order + block_order
```

使用以参与者为聚类单位、exchangeable 工作相关结构和稳健标准误的 Gaussian GEE。主要次要对比为 D-V；A-V 同时报告，两个维度对比使用 Holm 校正。有方向的 induced-source 差异和 `dimension × source` 属于描述或探索分析。

生理模型属于探索性：

```text
Delta_PE_A ~ eda_delta_within_person + hr_delta_within_person +
             prototype_A + stimulus + session_order +
             (1 | participant)
```

## 9. 操纵检查

- 报告每个视频的目标情绪和非目标情绪强度。
- 个体诱发命中定义为：目标情绪评分至少为 5，且不低于所有六个非目标情绪；并列最高计为命中并另行报告并列比例。
- 主分析保留所有有效试次，避免按结果选择样本。
- 仅命中试次分析作为敏感性分析。

## 10. 缺失与异常

- 不对 VAD 或生理指标做均值填补。
- 混合模型使用全部可用有效观测。
- 不按数值大小单独删除连续生理指标；仅依据预定信号质量标记排除 fail 试次。主要探索模型使用两个模态均 pass 的试次，partial 试次作为模态特异敏感性分析。对明显影响点报告含/不含结果，但不据其方向修改主观分析。
- 所有排除均输出逐步流程图和数量。

## 11. 多重比较与探索分析

- H1 是唯一主要检验，不校正。
- H2 的预定逐维比较使用 Holm 校正；H3 明确报告为探索性。
- 未在本文件列出的分析标为 exploratory，不使用“验证了假设”的措辞。
