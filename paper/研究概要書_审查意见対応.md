# 研究概要书审查意见对应

对应文件：`DREAMER_NRC_研究概要書_2頁版_再査読対応版.docx`

| 审查问题 | 概要书中的处理 | 仍然保留的边界 |
|---|---|---|
| 单个感情词不能代表整个词典 | 将研究对象明确限定为9个“感情类别标签”；写明同名名词是操作化，不是词典代表值；补充形容词敏感性分析 | 尚未完成近义词集合、原型词或词向量中心分析 |
| 推断对象只有9个点 | 明确推断单位为9类别，而非414试次；保留9!精确置换和Holm校正 | 仍是探索性类别层分析，统计能力有限 |
| 创新点不足 | 将贡献改为“评价间的对应程度因V、A、D维度而异”，而不是再次证明词义与体验不同 | 需要外部数据进一步验证普遍性 |
| Dominance解释薄弱 | 加入场景可控制性、主体性和自我决定感的语境依赖解释 | 该机制并未被现有二次数据直接检验 |
| CASE贡献不清 | 限定为4类别VA处理流程的补充确认，不再称为外部复现 | CASE不能支持D或充分再现 |
| 斜率不等于尺度差 | 改为“用回归斜率近似尺度差”；明确其不能分离量尺、刺激和样本影响 | 未加入方差比、ICC或测量不变性模型 |
| Bootstrap描述模糊 | 明确为23名参与者有放回抽样，并在每个感情内对2段影片有放回抽样，共5,000次 | 每类只有2段影片，刺激总体不确定性仍可能低估 |
| 学术意义偏弱 | 明确指出词典VAD不宜未经验证地直接替代影片诱发体验值 | 不否定词典VAD作为语义参照或预测特征的价值 |
| 当前只能比较不同样本 | 明确为类别层面的跨数据库对应，不是个体内预测 | 个体内关系留待同一参与者实验 |
| 图还可加入更多统计量 | 按用户要求保留原图；斜率、Spearman和bootstrap区间集中放在表1 | 图表存在部分统计信息重复，但两页内阅读路径更直接 |

## 第二轮审查追加对应

| 追加问题 | 本轮修改 | 判断依据 |
|---|---|---|
| 为什么采用名词标签 | 写明DREAMER以名词形式标示感情类别，因此用同名名词做一对一标签对应 | 这是一种标签层操作化，不是主张名词优于形容词或代表全部近义词 |
| 敏感性分析只有结论、没有数值 | 在结果中补充形容词分析的Pearson r与Holm校正p值 | V与A保持线性对应，D仍未确认对应 |
| 研究目的仍像“有没有差异” | 改为“明确VAD各维度的对应特性” | 将论文重心从二值判断转向维度模式 |
| 学术贡献仍偏抽象 | 明确联系到情感计算中的教师值、正解值使用 | 不把词典VAD直接等同于影片诱发情动体验 |
| 图中未写回归斜率 | 保留用户认可的原图，在图注明示“回归斜率见表1” | 避免图中标签、r、p、斜率同时堆叠；第二页表1承担精确数值查阅 |
| 为什么使用Pearson | 方法中写明研究问题包含线性对应，因此采用Pearson | Spearman继续承担排序对应的检验，二者角色分开 |

## 处理原则

- 能由现有数据支持的问题，增加直接证据或方法说明。
- 不能由现有数据解决的问题，收窄结论并明确列为限制。
- 不为了“回应审查”而虚构同义词分析、因果机制或外部再现。
