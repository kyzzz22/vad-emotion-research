VAD 3D 离线演示说明
====================

macOS 电脑
----------
1. 解压整个 ZIP 文件，不要只单独复制 index.html。
2. 双击 start_demo.command。
3. 浏览器会自动打开演示页面。
4. 演示期间不要关闭“终端”窗口。
5. 演示结束后，在终端中按 Control+C，或者直接关闭终端窗口。

如果 macOS 第一次阻止打开
-------------------------
方法一：右键点击 start_demo.command，选择“打开”，再确认“打开”。

方法二：在该文件夹打开“终端”，运行：

bash start_demo.command

如果系统提示没有执行权限，可以运行：

chmod +x start_demo.command
./start_demo.command

Windows 电脑
------------
1. 解压整个 ZIP 文件，不要只单独复制 index.html。
2. 双击 start_demo.bat。
3. 浏览器会自动打开演示页面。
4. 演示期间不要关闭黑色启动窗口。
5. 演示结束后，在启动窗口中按 Ctrl+C，或者直接关闭窗口。

页面操作
--------
- 默认进入“导览模式”：用左右箭头、底部章节点或键盘 ← / → 切换 6 章叙事。
- 点击顶部“自由探索”：返回原有的数据浏览器和右侧详情面板。
- 点击顶部“JA / 中”：切换中日文案和界面。
- 点击 3D / V / A / D：切换空间总览与逐维对照视图。
- 点击顶部 V / A / D 结果徽章：直接跳到该维度投影。
- 空格键：暂停或恢复自动旋转。
- 鼠标左键拖动：旋转三维空间。
- 鼠标滚轮：缩放。
- 点击情绪点或箭头：聚焦该情绪。
- 右侧下拉菜单：切换九种情绪或显示全部。
- 可分别显示/隐藏 NRC、DREAMER、偏移箭头和标签。
- “自动旋转”适合投影演示。
- 右上角回转箭头可恢复初始视角。

重要提示
--------
- 页面不需要联网，Three.js 已包含在 vendor 文件夹中。
- 不要直接双击 index.html，否则浏览器可能拦截模块加载并显示空白。
- 如果浏览器没有自动打开，请手动访问启动窗口显示的地址，通常是：
  http://127.0.0.1:8765/
- 如果 8765 端口已被占用，启动器会自动尝试后续端口，以窗口显示的地址为准。

备用启动方法
------------
如果电脑安装了 Python，也可以在该文件夹打开终端并运行：

python -m http.server 8765

然后访问 http://127.0.0.1:8765/
