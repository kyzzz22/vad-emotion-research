# 日语控制任务：技术演练原型 v0.1

仅用于研究者检查操作、时间戳、评分和导出。**不是可直接招募的实验**：日语SAM未核实、D为自拟文字占位题、R轨迹为合成正弦曲线且未匹配C表现。导出始终包含 `mode=technical_demo_only` 和限制列表。

启动：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory experiment/control-pilot
```

访问 http://127.0.0.1:8766 。加 `?short=1` 使用1秒练习/3秒区块；常规为10秒练习/60秒区块。A=CRRC，B=RCCR，由研究者按分配表指定。练习始终C并单独标记。

左右键/触屏按钮移动；4个区块后分两页回答（D先，其余后）。量表无预选值。区块中可中止；失焦/隐藏页面自动中止并记录。JSON导出含匿名演练ID、版本、顺序、每帧实际时间/位置/输入、评分及退出事件。仅保存在内存，刷新会丢失，请及时导出到受控目录；无服务器传输。

页面计时不是生理同步。轨迹约20Hz采样，浏览器可能抖动；按实际时间分析。手机仅支持操作演练，正式设备尚未选定。原A2网页完全独立保留。

下一步：核定日语测量、实现配对轨迹/表现匹配与分配、冻结设备及程序、通过预测试。见[六周计划](../../protocol/A2_六周验证计划.md)。

验证脚本：安装了 Playwright 与浏览器的环境中运行 `node experiment/control-pilot/test.cjs`。可用 `CHROME_CHANNEL=chrome` 指定本机 Chrome；依赖不加入仓库。
