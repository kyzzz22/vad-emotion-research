# A2 样本量决策

> 2026-09-28：以下为原三级 A2 的历史设计/方法材料，待修订，不作为当前新研究的招募或执行依据。当前工作见[可行性验证与决策门槛](A2_可行性验证与决策门槛.md)。原 H1、30–40 人规模、2026 年 7–8 月时间表及生理配置均未转用于新设计；通过决策关口后须同步更新预注册、材料、代码和分析。

## 当前能确定的结论

在没有本地预测试方差和事先规定的最小重要效应前，不能严谨声称“30 人足够”。当前先做透明的敏感性分析：把每名参与者在六个概念上的 `distance_PI - distance_LI` 取平均，定义其配对标准化效应为 `dz`，计算双侧 alpha = .05 下的精确配对 t 检验功效。该检验也是主要混合模型的参与者层稳健性分析。

运行：

```powershell
python analysis/power_sensitivity.py
```

结果写入 `results/power_sensitivity.csv`。招募数按 15% 退出或无效率向上调整。

## 冻结规则

预测试后、正式招募前完成以下步骤：

1. 先从理论和可解释性规定最小重要效应，不用预测试观察到的效应直接充当真实效应。
2. 用预测试估计参与者层 `PI-LI` 差异、概念差异和单元残差，另做与主要配对差 LMM 一致的 Monte Carlo 模拟。
3. 取配对 t 敏感性分析与 LMM 模拟中要求更高的完整样本数。
4. 若一个月内无法达到该样本，将研究明确注册为 pilot/estimation study，主要报告效应和区间，不将不显著结果解释为“没有差异”。

正式模拟命令模板如下。所有方差参数必须替换为预测试估计或更保守的外部依据，并保存完整命令：

```powershell
python analysis/power_lmm_simulation.py --sample-sizes 30,36,42,48,54 `
  --iterations 1000 --effect [最小重要原始距离差] `
  --participant-intercept-sd [值] --participant-slope-sd [值] `
  --concept-slope-sd [值] --residual-sd [值] `
  --output results/power_lmm_frozen.csv
```

当前仓库中的 smoke 结果仅验证代码可运行，不是最终样本量证据。

## 时间受限时的决策

- 完整样本达到功效目标：按确认性 H1 报告。
- 完整样本 30-目标值之间：保留预注册模型，但论文定位为先导研究。
- 完整样本低于 30：不做强确认性结论，重点报告可行性、测量质量和区间估计。
