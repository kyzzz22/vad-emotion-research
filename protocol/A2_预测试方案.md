# A2 刺激与措辞预测试方案

状态：执行草案。正式招募前须填写伦理编号、刺激访问方式和负责人。

## 1. 目的

预测试不重新建立影片常模，也不检验论文主要假设。它只回答四个执行问题：

1. 本地样本能否识别候选影片的目标情绪。
2. 每类两个候选刺激是否存在明显混合情绪或极端不适。
3. “被逗乐”和 Dominance 中文措辞是否被一致理解。
4. 视频播放、事件标记、评分导出和生理同步是否完整。

## 2. 样本

- 目标 8-12 名不进入正式分析的参与者。
- 纳入标准与正式实验一致。
- 预测试数据只用于冻结材料和流程，不与正式样本合并。
- 预测试开始前仍需满足所在机构对人体研究的伦理要求。

## 3. 材料与流程

- 使用 `materials/stimulus_manifest.csv` 中 12 个候选视频。
- 每段视频前 30 秒静息基线；视频后完成 VAD、7 个离散情绪强度、熟悉度、个人相关性和不适度。
- 六个试次后强制休息至少 3 分钟；参与者可随时暂停或退出。
- 负性刺激结束后播放已审批的中性恢复材料，并确认参与者状态适合离场。
- 影片顺序使用 `materials/schedules.csv` 中对应参与者的 induced 行。

## 4. 认知访谈

预测试结束后询问：

1. “被逗乐”与你理解的“喜悦”有什么不同？
2. “温情”主要指自己的感受、视频内容，还是对人物的评价？
3. “控制程度”指控制自己的感受、控制视频中的局面，还是其他含义？
4. 你在回答诱发评分时，是报告自己的感受，还是评价视频应该让人有什么感受？

研究者逐字记录回答，但不记录可识别身份信息。若多数人把 D 理解为“视频人物是否强势”，必须修改措辞并重新做小规模认知访谈。

## 5. 预先规定的材料决策

对每个视频报告目标情绪均值、最高非目标情绪均值、两者之差、个体命中率、VAD、不适度和熟悉度。

个体命中定义：目标情绪评分不低于所有非目标情绪，且目标评分至少为 5。并列最高计为命中，但另行报告并列比例。

硬性淘汰条件满足任一项即淘汰：

- 视频或事件标记无法稳定播放/同步。
- 目标情绪平均分低于 4.5。
- 目标情绪平均排名低于前两位。
- 平均不适度达到 8，或出现伦理方案规定的停止事件。
- 无法取得合法的实验展示权限或访问方式。

在未触发硬性淘汰时，同一概念优先保留目标减最高非目标差值更大、命中率更高、熟悉度更低的刺激。由于预测试样本很小，不用单个 p 值决定材料去留。愤怒刺激必须单独报告厌恶和悲伤评分；若目标差值不理想，则将愤怒标为混合情绪材料并做排除该概念的敏感性分析。

## 6. 冻结记录

预测试结束后生成一个带日期的材料冻结表，至少包含：

- `stimulus_id`、精确剪辑起止时间和文件校验值。
- 来源、访问日期、展示权限和是否允许公开。
- 预测试描述统计和保留/淘汰理由。
- 最终评分措辞和版本号。
- 设备、采样率、事件码和同步误差测试结果。

正式招募开始后不得依据正式结果更换刺激；任何不可避免的变更均作为预注册偏离报告。
