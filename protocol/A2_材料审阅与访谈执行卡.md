# A2 材料审阅与访谈执行卡

2026-10-03；研究者执行稿。先路线2，后路线1；路线3待定。具体日历从材料可用之日重新排，不把过去的计划日期记作完成日期。

## 本轮要回答什么

日本語のD評定において、参加者は何を評価しているのか。その理解は、課題の結果を自分の行動で変えられる感覚と、どのように関係するのか。

第一阶段产出是含义、歧义与版本修改记录；第二阶段才考察任务控制机会变化时的评分。首阶段不能回答词义—体验差异的因果机制。

## 材料审阅：预计1–3个工作日，取决于人员与原始材料可用性

研究者准备原始SAM说明、筑波英日相邻附录、当前自拟题三份材料，分别标明来源；原版尚未取得时不能将筑波英文说明标成原版。

建议邀请两位能阅读英日材料的人独立审阅，记录语言背景；这只是翻译质量流程，不构成标准化认证。逐项记录：

| 项目 | 审阅问题 | 记录要求 |
|---|---|---|
| 评价对象 | 自己、人物、词义还是任务？ | 写出原句及拟保留对象 |
| 时间窗口 | 当下还是整个任务？ | 固定一个窗口 |
| D两端 | 服从、社会地位、能力、外界控制、情绪调节是否混杂？ | 记录差异，不强制统一成控制感 |
| 跨维度 | 刺激／恐惧措辞是否被理解为A或V？ | 先记疑点，留待访谈 |
| 中间值 | 中性、两者兼具、无法判断是否被混用？ | 不将“不适用”编码为5 |
| 图示和方向 | 小到大是否对应1到9？ | 双人核对图示、导出值和反向计分 |

合并意见后形成v0.2，并保存“原句—改句—理由—审阅者—日期”记录。研究者必须说明改编内容；未经核定的自拟稿继续只用于软件演练。

## 第一轮认知访谈：建议先3–4人，约每人20–30分钟

人数为发现明显理解问题的工作安排，不是效度或统计效能计算。按适用机构程序完成说明与同意后开展。

1. 每人首次仅看到一版材料；记录材料版本。不要先讲“D就是控制感”。
2. 在明确、相同的评价情境后独立评分，再用[日语访谈稿](A2_日语访谈稿.md)开放追问。尚未完成任务匹配时，不把网页C/R差异用于效应结论。
3. 逐字记录参与者的评价对象、时间窗口、低高端解释及评分理由；不由研究者猜测其心理含义。
4. 最后才展示“改变外界结果／调整自己的情绪”两种候选释义；顺序平衡。提示后的理解另列，不能计入自发解释。
5. 两名编码者先独立编码再讨论分歧。若只有一名编码者，如实标注，不报告不存在的一致性。

## 访谈后的决策

- 若反复出现对象或端点误解：修改相关句子，换新参与者检查；跨版本的数据分开，不合并估计效应。
- 若理解以力量、地位或服从为主：保留这一发现，重新判断D是否适合控制任务；不能删掉这些回答以提高“符合率”。
- 若理解基本清晰：进入任务预测试，分别保留D与自拟控制感题；二者相关不代表同一构念。
- 若D无变化而控制感变化：报告操纵与D反应的分离，并考虑任务范围、测量理解与精度；不能直接宣布D无效。

## 进入控制任务预测试之前

必须先修正当前网页的C/R运动轨迹和表现不匹配问题，记录两条件的客观表现、成功反馈及体验难度；回放匹配也有先后顺序和配对依赖，需明确设计。确认评分版本、任务日志、随机／平衡顺序、排除规则及分析单位，再冻结材料。

预测试样本规模待任务与主要估计量明确后制定；不能用认知访谈人数代替。路线1的词义—体验比较仅在这些决策完成后展开。
