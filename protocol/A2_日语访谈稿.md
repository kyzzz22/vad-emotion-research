# 日语认知访谈稿 v0.1

2026-09-28。研究者审阅稿；未验证的日语题目。不是完整同意书。先核查最终D测量来源，再将对应版本插入本稿。不要同时展示多版定义后收集“自发理解”。

## 开始

「この面接では、質問の表現がどのように理解されるかを確認します。正しい答えを当てるテストではありません。答えたくない質問は飛ばすことができ、いつでも中止できます。」

按适用程序解释研究用途、保存期限、联系方式；录音另行取得同意。

## 独立评分后的开放追问

1. 「この質問は、何を尋ねていると思いましたか。ご自分の言葉で教えてください。」
2. 「その点数を選んだ理由を教えてください。」
3. 必要时：「答えるとき、誰の、あるいは何についての状態を考えていましたか。」
4. 必要时：「どの時点、またはどの時間帯のことを考えていましたか。」
5. 参与者自行说到控制时：「今おっしゃった『コントロール』とは、具体的にはどのようなことですか。」
6. 「一つ隣の点数を選ぶとしたら、何が違うと思いますか。」

先记录原话，不提示情境控制/情绪调节分类。区别自发、追问后及提示后回答。后续区块已经受到访谈提示，不能视为新的无提示基线。

## 最后才呈现的候选释义

A：「自分の行動によって、出来事の進み方や結果を変えられると感じること。」
B：「自分の感情の反応を調整できると感じること。」

「この二つは、どのように違うと思いますか。区別しにくい場合も、そのまま教えてください。」

A/B为研究者自拟释义，不是标准量表。顺序平衡并记录，不把提示后认可计作自发解释。
